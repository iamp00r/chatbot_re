# 작업 기록

백로그 항목(M0-1, M1-5 …)을 끝낼 때마다 한 파일씩 남긴다. **개발을 모르는 사람이 읽고, 남에게 설명할 수 있는 수준**으로 쓴다.
대화 기록을 뒤지지 않아도 "무엇을 만들었고, 어떻게 동작하며, 왜 그렇게 골랐는지"를 여기서 알 수 있게 하는 것이 목적이다.

- 언제: 기능 PR 안에 함께 넣는다(별도 PR을 만들지 않는다).
- 누가: Claude가 쓰고, 사용자가 PR 검수 때 읽어 보며 이해 안 되는 곳을 묻는다. 물어본 내용은 문서에 반영한다.
- 설계 전체는 `docs/02_기술명세서.md`, 여기는 "실제로 한 일과 그 이유"의 요약이다.
